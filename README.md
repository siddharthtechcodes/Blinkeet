## 🛒 Features

- **⚡ 10-Second Countdown Delivery Timer**: Delivering before you even finish thinking about what you ordered.
- **🚨 Interactive Neo-Brutalist UI**: High-contrast, bold aesthetic inspired by modern Indian quick-commerce parody.
- **🔊 Dynamic Sound FX & Buzzers**: Custom Web Audio synthesized buzzers, laugh tracks, and celebratory sounds.
- **😂 Satirical Grocery Catalog**: From "Emotional Support Maggi" to "Existential Dread Cookies".
- **📱 Fully Responsive**: Seamless experience on both mobile devices and desktop screens.
- **💸 Parody Checkout & Cart System**: Interactive cart drawer with sarcastic surcharges and instant order placement.

---

## 🛠️ Tech Stack

- **HTML5** & **Vanilla JavaScript** (Zero heavy dependencies)
- **Tailwind CSS** (via CDN for neo-brutalist utility styling)
- **Web Audio API** (Procedural sound synthesis without external audio files)
- **GitHub Pages** (Instant static site hosting)

---

## 🏃 Local Development

Run the static web app locally using PowerShell:

```powershell
powershell -ExecutionPolicy Bypass -File .\server.ps1
```

Or simply open `index.html` directly in any web browser!
